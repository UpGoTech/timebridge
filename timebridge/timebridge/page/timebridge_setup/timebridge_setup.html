TimeBridge connects biometric devices to this site and builds attendance from punch logs. Follow the steps in order.

1. Create masters (once)

  1. Open TimeBridge Organization and create your company.
  2. Open TimeBridge Branch and create the office. Select the Organization.
  3. Open TimeBridge Department and create a department (optional).
  4. Open TimeBridge Shift and create the shift with start and end times.

2. Create a TimeBridge Machine

Open TimeBridge Machine and click New.

Fill the form, then Save

  1. Machine ID — a unique code, for example GATE-1.
  2. Machine Name — a display name, for example Main Gate.
  3. Device Brand — ZKTeco, eSSL, or Other.
  4. Device Model — optional.
  5. Serial Number — the serial printed on the device. Required for ADMS; punches will not arrive without it.
  6. SDK Type
    • Choose ADMS if the device sends data to TimeBridge on its own.
    • Choose PyZK if TimeBridge must connect to the device and pull data.
  7. IP Address — the device IP address.

If SDK Type is PyZK

  1. Port — usually 4370.
  2. Communication Type — TCP/IP.
  3. Communication Password — the device comm key (often 0).
  4. Use UDP — leave this off unless the device only answers on UDP.

If SDK Type is ADMS

Skip steps 12–15. Port, password, and UDP are hidden.

  1. Keep Sync Enabled ticked.
  2. Do not fill Status, Last Contact, or Last Sync. TimeBridge writes these automatically.
  3. Click Save. The record name will look like BM-00001.

3. After you save (Device menu)

  1. Test Connection — use this for PyZK. ADMS devices are not pulled this way.
  2. Turn the device on and punch in / out.
  3. Fetch All Data — load users and punches from the device.
  4. Check TimeBridge Machine User. Enrolled users should appear there.
  5. Create & Link TimeBridge Employees — choose Organization, Branch, and Shift, review the preview, then confirm.
  6. Rebuild Attendance — turn stored punches into attendance rows.

For photographs, use Fetch Photos or Upload Photos.

4. Review the results

  1. Punches — TimeBridge Punch Log.
  2. Attendance — TimeBridge Attendance.
  3. Reports — Attendance Report or Punch Register. Select the month and machine.

Notes

  • Until you complete step 23, punches are stored but attendance is not created.
  • An ADMS machine is complete when the serial number is correct, the record is saved, users have arrived, and employees are linked.
  • A PyZK machine is complete when IP and port are set, the record is saved, Test Connection succeeds, data is fetched, and employees are linked.
